One sentence pitching a bizarre startup idea that sounds ridiculous at first glance but makes sense as a real business.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
We rent out office plants as emotional support coworkers — they never interrupt, they photosynthesize your stress, and they only ask for water.
```
